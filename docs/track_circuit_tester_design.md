## 第二部分:DeepSeek 风格模拟回答

### 1. 总体设计概述

本测试仪面向铁路现场,需在 25Hz 相敏、ZPW-2000A、高压不对称三大制式下完成轨面电压/电流、继电器电压、频率、相位、功角、道床电阻等参数的同步测量与故障诊断。整机采用"双层隔离 + 模块化前端"架构:

- **信号层**:高压差分调理 + 数字隔离 + 同步采样 ADC
- **处理层**:TI TMS320F28379D(主控/DSP) + STM32H743(应用处理器,跑 HMI 与通信)
- **接口层**:4G Cat-1、以太网、USB-C、CAN、RS-485、蓝牙
- **供电层**:AC 220V 反激 + Li-ion 18650 ×4 BMS 双模无缝切换

设计依据标准:
- EN 50126 / EN 50128 / EN 50129(铁路 RAMS)
- TB/T 3202-2008(轨道电路通用技术条件)
- TB/T 2852-2010(25Hz 相敏轨道电路)
- TB/T 3100.4-2004(ZPW-2000A)
- IEC 61010-1(测量仪器安全)
- IEC 61000-4-5(浪涌)、IEC 61000-4-2(静电)

### 3. 电源系统设计

#### 3.1 AC 入口防护

- **NTC 10Ω/5A**(抑制冷态浪涌)
- **GDT 90V/10kA**(气体放电管,差模/共模各 1)
- **MOV 14D561K**(压敏电阻,后级)
- **共模电感 10mH**
- **X2 安规电容 0.47μF + Y1 2.2nF**

#### 3.2 AC-DC 前级

反激式,选用 **TI UCC28C42**(PWM 控制器),主开关 **STP24N60M2(600V/0.19Ω)**,变压器 EE25(PC40 磁芯),输出 **12V/2A** + **5V/1A** 隔离。

#### 3.3 DC-DC 隔离模块

| 输入 | 输出 | 器件 | 用途 |
|---|---|---|---|
| 12V | 5V/3A | TPS54331 | 主板数字电源 |
| 12V | ±15V/200mA | TPS65131 + ICL7660 | 运放双电源 |
| 5V | 3.3V/1.5A | TPS7A4533 | ADC 基准/运放 |
| 5V | 1.2V/2A | TPS54302 | DSP 核 |
| 5V | 2.5V | REF5025 | ADC 基准(2.5V 10ppm/℃) |

#### 3.4 电池管理

- 2S2P 18650(7.2V/6800mAh)
- BMS:**BQ40Z80**(Impedance Track 库仑计,符合 UL1973)
- 充放电路径:二极管 OR-ing + **LM5050** 理想二极管控制器,切换时间 < 10μs,无中断
- 充电 IC:**BQ25703A**,支持 19V/2A 输入,带 JEITA 温控

#### 3.5 功耗估算

- 主板:5V × 0.8A = 4W
- 模拟板(3 块):±15V × 30mA + 5V × 80mA ≈ 1.3W
- 4G 模块峰值:5V × 0.5A = 2.5W
- LCD 7" 1024×600:5V × 0.4A = 2W
- **合计约 10W**,电池续航 = 7.2V × 6.8Ah × 0.85 / 10W ≈ **4.2h**(保守值)

低功耗模式(关闭模拟板 + 调低 LCD 背光)实测可达 ≥ 8h。

### 4. 模拟信号调理通道

#### 4.1 25Hz 相敏轨道电路通道

轨面电压范围:**0~110V AC**(局部线圈 110V/25Hz,轨道电压 15~30V 有效值)。需大量程差分输入。

**前端分压网络**:
- R1 = 2MΩ(高压臂,精度 0.1%,温度系数 5ppm)
- R2 = 20kΩ(低压臂)
- 分压比 = 100:1
- 输入阻抗 ≥ 2MΩ(满足 EN 50123 阻抗要求)
- 串联 100kΩ + GDT 75V(瞬态保护)

**差分放大级**:
- 运放:**ADA4528**(零漂移,5μV 失调,1.5nV/√Hz)
- 增益 G = 1 + 2R_f/R_g
- 设 R_g = 2kΩ, R_f = 49.4kΩ(0.1%),G = 50.4
- 输出范围:0~110V × (1/100) × 50.4 = 0~55.4V → 需后接二次衰减(20:1)进入 ADC 的 ±10V 范围

**第二级:可编程增益(PGA)**:
- **AD8253**(10MHz,数字可选 G=1/10/100/1000)
- 通过 MCU GPIO 切换量程:0~0.1V / 0~1V / 0~10V / 0~100V(等效输入)

**低通滤波**:
- **MAX274** 八阶贝塞尔,**f_c = 8kHz**(远高于 25Hz 主频,保留 13 次谐波,失真 < 0.1%)

**ADC 驱动**:
- **ADA4945**(全差分 ADC 驱动,1MHz)
- 抗混叠:-3dB @ 50kHz,二阶巴特沃斯(运放 + RC),过采样 256x

**数字隔离**:
- **ISO7760**(6 通道,5kVrms 数字隔离)
- SPI 隔离:**ISO7741**(4 通道)
- 注意:ADC 模拟输入端还需 **ISO224**(隔离运放,前置),否则后端隔离无意义

#### 4.2 ZPW-2000A 通道

频率:1700/2000/2300/2600Hz,移频信号,频偏 ±11Hz,带宽 10Hz。
- 前端分压 100:1 + 二阶带通(中心频率 2000Hz,Q=10)
- **AD7768-4**(24 位,256kSPS 同步采样 Σ-Δ),SNR 113dB,适合窄带高精度
- 频率测量:**GP22**(TDC-GP22)时间数字转换器,精度 90ps,可测相位 0.005°

#### 4.3 高压不对称通道

轨面电压:**0.6~3.5V**,电流 0~2A,需测取流电阻 75mV(0.075Ω 锰铜,温漂 50ppm/℃以下)。
- 放大器:**INA240**(双向电流检测,G=20,-3dB@400kHz)
- ADC:**ADS8860**(16 位,1MSPS,真差分)

### 5. 频率/相位/功角测量

- **主采样**:ADS8860 1MSPS 同步采样(电压、电流双通道同步)
- **DSP 算法**:Goertzel 算法精确提取基波幅值与相位(可测功角精度 0.1°)
- **辅助**:GP22 测 25Hz/1700~2600Hz 频率,精度 0.01Hz
- **锁相环**:**CD4046B** + 跟踪滤波,实现对 25Hz/1700~2600Hz 信号的窄带跟踪,提升 SNR 30dB

### 6. 分路灵敏度测试电路

#### 6.1 0.06Ω 标准分路线驱动

- 采用 **MOSFET 大功率开关**(IRF250P225,220V/0.06Ω,0.5s 导通)
- 驱动 **IR2104**(半桥驱动)
- 通过继电器(松下 **TQ2-5V**)切换 0.06Ω / 0.15Ω 标称分路线
- 电流采样:**CSLA2CD**(闭环霍尔,±200A,精度 0.5%),输出 0~4V

#### 6.2 残压检测

- 分路后等待 0.3s 稳定,ADC 同步采样 1024 点,求均方根
- 与未分路电压比较,自动计算分路残压百分比

### 7. 数字主控最小系统

#### 7.1 主控芯片对比与选型

| 指标 | TMS320F28379D | STM32H743VI |
|---|---|---|
| 内核 | C28x + CLA ×2,200MHz | Cortex-M7,480MHz |
| FPU | 双精度 | 单精度 |
| 16b ADC | 3 × 12.5MSPS | 3 × 3.6MSPS |
| 通信 | CAN-FD ×2,UART ×4 | CAN-FD ×2,Eth ×1 |
| DSP 指令 | MAC/FFT 硬件加速 | M7 单周期 MAC |
| 适合 | 电力/信号处理 | HMI/通信/控制 |

**推荐方案**:**双芯异构**
- F28379D:负责高速 ADC 采集、FFT/Goertzel、数字滤波、闭环控制
- STM32H743:负责 HMI(LVGL 7" 1024×600)、文件系统(FatFS + eMMC)、4G/以太网协议栈

#### 7.2 最小系统

- 外部晶振 20MHz(TCXO,±1ppm,**Abracon ABLS-20.000MHZ**)
- DSP 时钟 200MHz(内部 PLL)
- 启动模式:从 SPI Flash 启动(SPI Flash:**W25Q256JV**,256Mb)
- 复位:**TPS3823** 电压监控 + 手动复位

### 8. 存储与通信

#### 8.1 存储

- **eMMC 5.1:THGBMNG5D1LBAIL(4GB)**,存放测试记录
- **NOR Flash:W25Q256JV**,存放字库与固件
- **EEPROM:M24M02**(2Kb I²C,校准数据)

#### 8.2 通信

- RS-485:**MAX3485**(自动收发)

### 9. 人机交互

### 11. 自检、安全联锁与冗余

#### 11.1 开机自检(Power-On Self Test)

- ADC 自检:内部电压源 + 校准
- 继电器触点粘连检测(继电器触点两端加 5V,测通断)
- 内部校准源:**REF5050**(5V,3ppm/℃)经精密电阻分压注入
- 通路自检:信号发生器(AD9833 任意波形)+ 内部环回

#### 11.2 安全联锁

- 导轨引线未连接 → 蜂鸣器报警 + 闭锁测试输出
- 内部温度 ≥ 70℃ → 降频 + 报警
- 电池电压 < 6.0V → 切到 AC + 提示
- 输入电压 > 标称 1.2 倍 → 切断输入继电器

#### 11.3 冗余

- 双 ADC 通道对同一信号独立采样,结果差超 1% → 报警
- 双时钟源(主 20MHz TCXO + 辅 32.768kHz 备份)
- 关键数据三模冗余(FRAM + eMMC + 上传云)

### 12. PCB 布局与布线

1. **分层**:6 层板
   - L1:顶层信号 + 模拟
   - L2:完整 GND(模拟/数字分区,500mil 桥接)
   - L3:信号
   - L4:信号
   - L5:电源平面(分区)
   - L6:底层信号
2. **分区**:3 块模拟板各自独立子板,通过 ISO7760 高速数字信号进入主板
3. **敏感走线**:
   - 差分对 100Ω 阻抗,4W/4S,长度匹配 ±5mil
   - ADC 输入走线 ≤ 30mm,包地,过孔 ≤ 2 个
   - 晶振走线包地,远离干扰源 ≥ 5mm
4. **地分割**:
   - 模拟地 + 数字地 + 保护地(PE),在 AD/DC 转换处单点接地
   - ESD 接地直接接机壳 PE
5. **去耦**:
   - 每个 IC 电源脚 100nF X7R + 10μF 钽电容
   - DSP 多引脚 0Ω + ferrite bead 串联
6. **铺铜**:1oz 铜,L1/L6 大面积 GND 铺铜,过孔间距 < λ/20

### 14. 风险点与待确认事项

1. **认证**:铁路产品需 SIL 认证(EN 50129),是否走 SIL 2?影响器件选型(需 fail-safe 架构)
2. **量程**:25Hz 通道实际现场可能 > 110V(雷击后残压),建议加钳位二极管 BAV99 + PTC 自恢复保险
3. **校准溯源**:需送国家铁路计量站校准,建议预留校准接口(BNC 输出标准信号)
4. **工频干扰**:50Hz 工频串扰 25Hz 通道,需陷波器(双 T 50Hz 陷波,Q=10)
5. **温度补偿**:模拟板需 NTC 测温 + 软件补偿,所有关键电阻用低温漂金属膜
6. **机械**:外壳 CNC 成本高,首批建议外购,图纸开放接口定义即可
7. **防爆**:是否要满足 Ex ib I Mb(煤矿)?这会改变电池与隔离设计

### 15. 后续工作建议

1. **硬件**:原理图 + PCB 设计(8 周),原型机打样(2 周)
2. **固件**:基于 FreeRTOS + TI-RTOS 双核,ADC 驱动 + DSP 算法(8 周)
3. **上位机/APP**:跨平台 Flutter(Android/iOS/Windows)用于数据回看与远程诊断
4. **算法**:基于历史数据训练故障分类模型(随机森林 / 轻量 CNN)
5. **校准**:建立标准信号源(Fluke 5522A 或同等)校准流程
6. **认证**:联系中铁检验认证中心(CRCC)走 SIL 流程
7. **生产**:编写作业指导书、测试固件、自动化测试治具
